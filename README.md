# Agent Foundry

Agent Foundry is a local toolkit for giving coding agents durable project context,
reusable skills, and safe, testable MCP capabilities.

## Repository layout

- `skills/` — reusable instructions and workflows for agents.
- `mcp-servers/` — local MCP servers that expose focused tools and resources.

The project will grow around three principles:

1. Tools should be useful to an agent, not merely decorative.
2. Side effects should be explicit, auditable, and permission-aware.
3. Every capability should have tests and a small usage example.

## Planned first capabilities

- Project and memory search
- Notebook and artifact inspection
- Diff and verification summaries
- Secret and configuration checks
- Decision and task tracking
